# jadonm.com

Static HTML with Make and Pandoc. Requires GNU Make, Pandoc 3.x and Python 3.
Run these commands from this directory (on Windows, use WSL).

```sh
make
```

The homepage is generated from `templates/index.html` and `log.json`.
Posts in `content/posts/*.md` build to `posts/*.html` using
`templates/post.html`. Commit the generated HTML alongside the sources;
hosting needs no build tools. Existing hand-written pages remain independent.
The homepage keeps `index.css`; posts load it plus `post.css`.
Keep the shared column, site title, spacing and footer in `index.css` so
navigation between the homepage and posts stays visually consistent.
Use `post.css` for article typography, code, tables and other post content.
The site title on posts links back to the homepage.

## Homepage log

```sh
make log                         # list stable IDs, dates and Markdown text
make update-log ID=example DATE=2026-10-17 TEXT='A new [project](https://example.com/).'
make update-log ID=example TEXT='An updated description.'
make update-log ID=example DATE=2026-10-18
make remove-log ID=example
```

`update-log` adds or edits an entry and rebuilds the homepage. New entries
default to today's date; edits keep the existing date unless `DATE` is supplied.
Use ISO dates (`YYYY-MM-DD`); the homepage displays `DD/MM/YY` with newest
entries first. Text supports inline Markdown. IDs use lowercase letters,
numbers, dots, underscores or hyphens. `log-update` and `log-remove` are aliases.
Removing a log entry keeps any linked post and its source.

You can also edit `log.json` directly and run `make`.
In Make command arguments, write `$$` for a literal dollar sign.

## Posts

Add `content/posts/my-post.md` with YAML front matter:

```markdown
---
title: My post
date: 2026-10-17
---

## First section

Post text.
```

Run `make`, then add a homepage link with
`make update-log ID=my-post TEXT='[My post](posts/my-post.html)'`.
An optional `updated` date is displayed alongside the publication date.
Code highlighting, a table of contents and MathML are generated by Pandoc.
Relative asset links are resolved from the output `posts/` directory.

Use a fenced `.dropdown` block for collapsible Markdown content. Its `summary`
sets the visible label, and the dropdown starts closed.

```markdown
::: {.dropdown summary="More details"}
Markdown content, including lists and tables.
:::
```

`make clean` removes only HTML generated from current Markdown posts.
`make -B` forces a complete rebuild. To preview locally:

```sh
python3 -m http.server 8000
```

Open `http://localhost:8000/`.
